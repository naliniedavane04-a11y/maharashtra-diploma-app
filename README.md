# 🎓 DTE Maharashtra Diploma College Predictor

A full-stack web application designed to help 10th-grade students in Maharashtra find eligible diploma colleges based on their SSC percentage, reservation category, preferred district, and branch choices.

## ✨ Features
- **Smart Eligibility Filtering:** Instant cutoff matching based on user percentage and category (SC, ST, OBC, OPEN, EWS, TFWS).
- **Multi-Filter Support:** Filter by District (Nagpur, Pune, Nanded, etc.), College Type (Government vs Private), and Branch.
- **Complete College Details:** Displays approximate annual fees and hostel availability/costs.
- **Responsive UI:** Built with Tailwind CSS for seamless mobile and desktop experience.

## 🛠️ Tech Stack
- **Frontend:** HTML5, JavaScript (Fetch API), Tailwind CSS
- **Backend:** Python, FastAPI, Uvicorn
- **Data Engine:** Pandas, CSV Dataset
- **Deployment:** Vercel (Frontend) & Render (Backend)
